# Clawd

Android-приложение: пиксельный Clawd поверх официального приложения Claude (служба специальных
возможностей + окно-оверлей). Чистая Java, без Gradle и библиотек. Код в
`app/src/io/github/yakstork/clawdbuddy/`.

Сборка и проверка: `./build.sh` → `build/Clawd.apk`. Комментарии и строки интерфейса — по-русски.
План и статус работ — в `PLAN.md`.

## Правила кода

1. **Сначала думай.** Не додумывай молча: неясно — спроси, есть несколько трактовок — назови их.
   Видишь путь проще — скажи.
2. **Проще.** Минимум кода, который решает задачу. Никаких фич, настроек, абстракций и обработки
   невозможных случаев «на будущее». Никаких новых зависимостей.
3. **Точечные правки.** Меняй только то, что нужно задаче. Соседний код, комментарии и
   форматирование не трогай, чужой мёртвый код не удаляй — упомяни. Убирай только то, что стало
   лишним из-за твоей правки. Держись стиля файла.
4. **Проверяемая цель.** У задачи есть критерий готовности; для исправления бага — сначала тест,
   который его ловит, если логику можно проверить без устройства. В конце — `./build.sh`.
