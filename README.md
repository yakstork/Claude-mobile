# Clawd для Claude

Маленький пиксельный Clawd, который сидит над полем ввода **официального** приложения Claude на Android:
печатает на ноутбуке, пока Claude отвечает, подпрыгивает, когда ответ готов, прыгает от нажатия.

Официальное приложение **не изменяется**: та же подпись Anthropic, вход через Google, обновления из Play Маркета.
Clawd живёт в отдельном приложении и рисуется в своём окне поверх Claude.

## Как это работает

- Служба специальных возможностей смотрит **только окна Claude**: где поле ввода и есть ли кнопка «Стоп».
  Ничего не сохраняет и никуда не отправляет. У приложения нет разрешения на интернет.
- Пока Claude не открыт, служба получает только события смены окон, без содержимого других приложений.
- Clawd появляется плавно, когда окно Claude открылось и поле ввода встало на место, и исчезает сразу,
  как только ты уходишь из Claude.

## Установка

1. Скачай `Clawd.apk` и установи (Android попросит разрешить установку из этого источника).
2. Открой **Clawd** → «Включить в спецвозможностях» → найди Clawd в списке и включи.
3. Если переключатель серый и пишет «Ограниченная настройка»: настройки приложения Clawd → ⋮ вверху справа →
   «Разрешить ограниченные настройки», потом снова включи службу.
4. Открой Claude.

Android время от времени может напоминать, что у Clawd есть доступ к экрану. Это нормально для любой службы
специальных возможностей.

## Настройки

Размер, цвет, высота посадки над полем ввода, анимации (печатает за ноутбуком, прыгает или танцует после ответа) и вибрация. Вдоль поля ввода Clawd можно двигать пальцем
прямо в Claude — место запоминается.

## Ограничения

- Снаружи нельзя перекрасить сам интерфейс Claude: для этого пришлось бы менять приложение.
- При очень резком выходе из Claude Clawd может на долю секунды задержаться: система сообщает о смене окна
  с небольшой задержкой.
- Окно Clawd чуть выше рисунка (запас под прыжок), поэтому узкая полоска прямо над его головой ловит нажатия.
- Рисунок и анимации свои, в пропорциях Clawd с claude.ai: оригинальные анимации зашиты в код приложения
  Claude, и достать их, не трогая приложение, нельзя.
- Кнопку «Стоп» Clawd узнаёт по подписи («Stop response», «Остановить ответ» и т. п.). Если он не печатает,
  пока Claude отвечает, — в Clawd → «Проверка» → «Скопировать отчёт» и пришли отчёт: в нём только кнопки
  и рамки вокруг поля ввода, без текста чата.

## Сборка

Нужны Java 17+, git, curl и zip. Android Studio не нужна:

```sh
./build.sh
```

Инструменты скачиваются в `tools/`, результат — `build/Clawd.apk`. Ключ подписи создаётся в `keystore/`
(в git не попадает): сохрани его, иначе следующая сборка не встанет поверх установленной.

Неофициальное приложение, не связано с Anthropic.
